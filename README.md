# 집그림 (zip-grim)

방과 화장실 개수를 고르면 평수와 공간 크기가 정해지고, 방·거실·주방·욕실·현관 조각을 끌어다 나만의 집을 그리는 웹앱입니다. 다 그린 집과 비슷한 크기의 아파트를 대전 구별 실거래가로 찾아 주고, 그 집을 사려면 월급을 몇 년 모아야 하는지 견적서로 보여 줍니다.
